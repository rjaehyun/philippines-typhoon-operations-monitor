# Data sources

## 1. Tropical cyclone tracks

- **Dataset:** International Best Track Archive for Climate Stewardship (IBTrACS), version 4r01
- **Provider:** NOAA National Centers for Environmental Information (NCEI)
- **Source:** https://www.ncei.noaa.gov/products/international-best-track-archive
- **Planned subset:** Western Pacific basin (`WP`), filtered to storms relevant to the Philippines
- **Available formats:** CSV, NetCDF, and shapefiles
- **Coverage:** Global historical tropical cyclone records; exact dates will be confirmed after downloading the selected subset
- **Reuse and attribution:** NOAA describes IBTrACS as publicly available and asks users to cite the dataset. See NOAA’s citation guidance at the source link above.
- **Retrieved:** 2026-11-17
- **Caveats:** IBTrACS combines data from multiple agencies. Track and intensity values may differ by agency and can have known historical data issues. This project summarizes historical tracks; it is not an official warning or forecast.

## 2. Philippine administrative boundaries

- **Dataset:** Philippines administrative boundaries (Common Operational Dataset)
- **Provider:** Humanitarian Data Exchange (HDX)
- **Source:** https://data.humdata.org/dataset/cod-ab-phl
- **Planned level:** To be selected after confirming available boundary levels and project needs
- **Available formats:** To be confirmed on the HDX dataset page
- **Coverage:** Philippines; exact geographic level and version to be confirmed after download
- **Reuse and attribution:** To be confirmed from the dataset page and the downloaded dataset’s metadata before use.
- **Retrieved:** 2026-11-17
- **Caveats:** Boundary vintages and geographic codes may not align perfectly with all storm records or other datasets. Record the selected dataset version and any applicable attribution here.
